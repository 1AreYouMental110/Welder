# Welder
Welder is a roblox script that simply welds you to anything, you can change settings like animation, weld position, velocity, rotation, etc. There is also a preset section where more advanced features go. Users can create their own weld presets (though it may be hard to try and code one), and distribute that code.
The script is all open-source.
